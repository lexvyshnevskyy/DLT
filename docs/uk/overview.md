# Delatometry ROS 2 — Огляд

Delatometry — робочий простір **ROS 2 Jazzy** для температурних експериментів на Raspberry Pi (або подібному Linux-хості). Система керує нагрівальним каналом LTM2985, синхронно знімає вимірювання, зберігає результати в **MariaDB** і надає **веб-HMI** та опційний **дисплей Nextion** по RS-232.

## Що робить система

1. **Програми** — багатокрокові температурні профілі (40–1600 K) з опційним розгортом частот E7-20.
2. **Керування в core** — PI-нагрів, планувальник програм і журнал вимірювань у вузлі `core` (не у веб-інтерфейсі).
3. **Збереження** — програми, кроки, запуски та часові ряди в MariaDB через вузол `database`.
4. **Інтерфейси оператора** — FastAPI (порт 80 за замовчуванням) та `hmi` для панелі Nextion.

## Головний принцип

> **Експериментами керує core.** Веб-інтерфейс і HMI лише запускають, зупиняють, налаштовують і відображають. Після перезапуску браузера програма на пристрої продовжує виконуватися.

## Структура репозиторію

| Шлях | Призначення |
|------|-------------|
| `src/core` | Планувальник, PI/PWM, `/core/query`, статус |
| `src/webui` | FastAPI та міст до БД і core |
| `src/database` | MariaDB, сервіс `/database/query` |
| `src/hmi` | Дисплей Nextion по UART |
| `src/ltm2985_uart` | Температура / канал керування LTM |
| `src/measure_device` | Зовнішнє вимірювальне обладнання |
| `src/ads1256` | Опційний вузол АЦП |
| `src/msgs` | Повідомлення та сервіси |
| `scripts/install.sh` | Повне встановлення та перезбірка |
| `scripts/systemd/` | Юніти systemd |
| `docs/en`, `docs/uk` | Документація (також у веб-UI **Документація**) |

## Швидкий старт

```bash
cd ~/ros2_delatometry
bash scripts/install.sh
# Повне встановлення або перезбірка; відкрийте http://<ip-пристрою>/
```

Конфігурація: `/etc/default/delatometry`  
Застарілі нотатки: `documents/` (краще використовувати `docs/`).

## Мови документації

- Англійська: `/docs/en` у веб-UI або `docs/en/` у репозиторії.
- Українська: `/docs/uk` або `docs/uk/`.
